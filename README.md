# Response Diversity Workshop 2026 website

Static website for the workshop at Kräuterhotel Edelweiss, Mount Rigi, 8–10 December 2026.

## Live website

https://responsediversitynetwork.github.io/RD-Workshop-2026/

## Publishing with GitHub Pages

The repository should contain the files and folders from this package directly at its root. In the repository settings, configure **Pages → Deploy from a branch → main → /(root)**.

The empty `.nojekyll` file is intentional.

## Main files

- Home: `index.html`
- Preliminary agenda: `agenda.html`
- Participants: `participants.html`
- Travel: `travel.html`
- Venue: `venue.html`
- Scientific glossary and methods overview: `concepts.html`
- Prototype explorer: `explorer.html`
- Administrative information: `administrative.html`
- Styles: `assets/css/style.css`
- Images: `assets/images/`
- Navigation script: `assets/js/main.js`
- Reimbursement form: `assets/docs/reimbursement-claim.docx`

## Privacy

Do not add the workshop organisation spreadsheet, participant registration details or the SNSF application to this public repository. The participant page contains only short research teasers based on publicly available profiles.
